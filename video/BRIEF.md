# Mine MCP demo — art direction

Core message: give a connected AI eyes and hands inside the real Minecraft client.

Audience: Minecraft Java players and developers browsing CurseForge.
Output: 1920×1080 H.264 MP4, 30 fps, 50 seconds, English narration and burned captions; French subtitles supplied separately.

Mood: precise, curious, confident. Calm/sharp motion with one cubic-out easing family. Base unit 0.4 seconds; match-cuts and crossfades only. Elements enter over 0.4 or 0.8 seconds with a 60 ms stagger, no bounce. Holds last at least 0.4 seconds. Hero content moves; small labels and background grids remain still.

Visual system: warm paper #f1f2eb, ink #111c19, acid green #c2f54a and muted gray #7e8982. Large geometric type and mono tool names. Original isometric network-cube mark. One main idea per scene.

Story: disconnected agent → Mine MCP bridge → observe → act → verify → 45 tools → installation and boundaries. Real game captures are labeled as real Minecraft 1.21.11 footage. Motion overlays are explanatory graphics, not a claimed in-game interface. Scripted tool calls illustrate the MCP connection; this is not a claim of an autonomous model completing an unscripted task.

Evidence: 49/49 local runtime checks in 1.14.4 and 1.21.11; 1.20.1 client smoke. 44 versions have compatibility symbol catalogs, not 44 complete gameplay tests. Alpha/Fabric/client only. No claim of unseen server data or elevated permissions.

Workflow guidance: iart.ai's MIT-licensed motion-art-direction, remotion-video and explainer-video skills from https://github.com/iart-ai/motion-skills, https://github.com/iart-ai/motion-design-skills and https://github.com/iart-ai/explainer-video-skills. No third-party video templates or artwork are copied.
